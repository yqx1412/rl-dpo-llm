# Core RL-for-LLM stack.

# These are minimum-version floors, not exact pins. The code uses TRL's
# `processing_class=` DPOTrainer API and `max_length`/`max_prompt_length` on
# DPOConfig, both of which are stable from the versions below onward (verified
# against current TRL main). Lower bounds keep the project installable on
# Colab, which ships a recent Python + torch that an exact `torch==` pin would
# conflict with.
#
# torch is intentionally NOT pinned: on Colab/most GPU boxes it is preinstalled
# with the right CUDA build, and re-pinning it is the usual cause of
# "no matching distribution" errors. Install torch via your platform if absent.
